# openai-stream-proxy platform package

This is a platform-specific native package for `@czp3009/openai-stream-proxy`.

It is installed automatically as an optional dependency of the main npm package when the current OS and CPU match this
package. It is not intended to be installed, imported, or run directly.

Use the main package instead:

```bash
npx @czp3009/openai-stream-proxy
```
